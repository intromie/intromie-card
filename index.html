ความปลอดภัยของข้อมูล
รูปภาพและข้อมูลในการ์ดนี้จะถูกจัดเก็บในระบบ
ที่มีการควบคุมและป้องกันการเข้าถึงในระดับที่เหมาะสม
เพื่อรองรับการใช้งานทั่วไปอย่างปลอดภัย

ระบบนี้ถูกสร้างขึ้นเพื่อการใช้งานส่วนบุคคลและเชิงสร้างสรรค์
อย่างไรก็ตาม ไม่ได้ออกแบบมาเพื่อจัดเก็บข้อมูลสำคัญ
หรือข้อมูลส่วนบุคคลที่มีความอ่อนไหว

ขอแนะนำให้หลีกเลี่ยงการอัปโหลดข้อมูลส่วนตัว
หรือข้อมูลที่ไม่ควรถูกเปิดเผยต่อผู้อื่น

ผู้ใช้งานเป็นผู้รับผิดชอบต่อเนื้อหาและข้อมูลที่อัปโหลดด้วยตนเอง
โปรดพิจารณาความเหมาะสมของข้อมูลก่อนทำการอัปโหลด

Data Security
Images and content on this card are stored in a system with
appropriate access controls and protections for general use.

This system is intended for personal and creative use.
However, it is not designed for storing sensitive, confidential,
or highly personal information.

We recommend avoiding uploads of personal data
or any content that should not be shared with others.

Users are solely responsible for the content they upload.
Please ensure that all uploaded content is appropriate before proceeding.

Set Edit PIN
Edit PIN is used to edit and manage this card.
Anyone with the Edit PIN can change images and content.
Keep this PIN private and do not share it with others.
Lock Card
ตั้งรหัส Lock PIN
Lock PIN ใช้สำหรับจำกัดการเข้าถึงการ์ดนี้
เฉพาะผู้ที่มี Lock PIN เท่านั้นจึงจะสามารถเปิดดูเนื้อหาได้
แนะนำให้ตั้ง Lock PIN ให้แตกต่างจาก Edit PIN
เพื่อช่วยลดความเสี่ยงในการถูกแก้ไขข้อมูลโดยไม่ได้รับอนุญาต
⸻
Set Lock PIN
Lock PIN is used to restrict access to this card.
Only users with the correct Lock PIN can view the content.
It is recommended to set a Lock PIN that is different from the Edit PIN
to reduce the risk of unauthorized content modification.
